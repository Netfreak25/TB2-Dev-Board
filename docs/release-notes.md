# TB2 Dev Board v1.0.1 - Hardware Rev. 1.0

Manufacturing package for the 42 x 20 mm Flipper-to-SOP8 adapter board.

**Unverified build candidate:** the production files have completed supplier review, but the finished mini-board and final supplied components have not yet completed physical validation. Reset through target-power interruption was tested and accepted on the preceding setup.

## PCBWay uploads

- `Gerber.zip` -> Gerber files
- `BOM.csv` -> Parts List (BOM)
- `Centroid.csv` -> Centroid file
- `Assembly-documents.zip` -> Assembly other files

`TB2-Dev-Board-Rev1.0.fzz` is included for editing. Use the supplied `Gerber.zip` when manufacturing this unchanged revision. `SHA256SUMS.txt` contains the checksums of all five design and manufacturing attachments.

See `docs/pcbway-ordering.md` for the complete ordering configuration and `README.md` for the board description and supported software.
